## 1. Назначение программы

MyCodeApp — текстовый редактор для исходного кода и больших текстовых файлов.

**Функции программы:**
- просмотр и правка текстовых файлов в кодировках UTF-8, UTF-16, Windows-1251,
  Latin-1 с сохранением исходной кодировки и переводов строк;
- просмотр файлов размером до 1 ГБ (файлы от 256 МБ — только для чтения);
- подсветка синтаксиса C/C++, Python, QML/JavaScript, CMake, JSON, Markdown (в Markdown —
  заголовки, выделение, ссылки, списки, таблицы и код C++/Python/JS внутри ```);
- значки файлов по языку в дереве, вкладках и поиске; образец цвета при наведении
  на `#rrggbb`, `#rgb`, `rgb()`/`rgba()`;
- правка несколькими курсорами, сворачивание блоков, сниппеты;
- работа с папкой проекта: дерево файлов, поиск по всем файлам, быстрый
  переход к файлу, сохранение набора открытых вкладок;
- автодополнение, переход к определению, поиск ссылок, переименование,
  форматирование и проверка кода с помощью языковых серверов;
- работа с Git и Mercurial: состояние файлов, просмотр изменений, коммит, ветки,
  история с графом веток;
- сохранение несохранённых правок при сбое и их восстановление;
- настройка темы, горячих клавиш, сниппетов; расширение плагинами;
- интерфейс на русском и английском языках.

**Ограничения:**
- файлы больше 2 млрд символов не открываются;
- файлы от 256 МБ в UTF-8 и Latin-1 открываются только для чтения;
- отправка изменений на сервер (push, pull, fetch) не выполняется:
  программа не обращается к сети;
- история показывает до 5000 последних коммитов.

## 2. Условия выполнения программы

**Аппаратные средства:**
- процессор x86-64;
- оперативная память — от 4 ГБ (для файлов от 100 МБ рекомендуется 8 ГБ);
- свободное место на диске — 150 МБ для программы и место под данные;
- видеоадаптер с поддержкой Direct3D 11 или OpenGL 2.1 (при отсутствии
  используется программная отрисовка).

**Программные средства:**
- Windows 10 или Windows 11, 64-разрядная;
- для помощи языкового сервера (необязательно) — установленные серверы:

| Язык | Сервер | Где взять |
|---|---|---|
| C, C++ | clangd | находится автоматически в Qt Creator или LLVM; для точного разбора нужен `compile_commands.json` в папке проекта или в `build/*` |
| QML | qmlls | находится автоматически в установленном Qt |
| Python | pyright | `npm install -g pyright` |
| Rust | rust-analyzer | установщик rustup |

- для коммитов Git — заданные имя и почта автора:
  `git config --global user.name "Имя"` и `git config --global user.email "почта"`;
- для ассистента (необязательно) — Ollama или другой сервер модели и модель
  Qwen3-4B-Instruct (раздел 3.11); на компьютере с сервером — ещё 4 ГБ свободной
  оперативной памяти;
- для репозиториев Mercurial (необязательно) — установленный Mercurial (проверено
  с версией 7.1; программа `hg`; находится в `PATH`, в `C:\Program Files\Mercurial` или
  `C:\Program Files\TortoiseHg`) и заданный автор: строка `username = Имя <почта>`
  в разделе `[ui]` файла `%USERPROFILE%\mercurial.ini`.

**Квалификация оператора:** навыки работы в Windows; для функций контроля версий и
языковых серверов — знакомство с соответствующими инструментами.

## 3. Выполнение программы

### 3.1 Установка и запуск

**Установка.** Распакуйте архив `MyCodeApp-<версия>-win64-portable.zip`
в любую папку. Программа не требует прав администратора.

Папка `data` внутри архива включает **портативный режим**: все настройки
хранятся в ней, и программу можно переносить на другой компьютер вместе
с настройками. Чтобы хранить настройки в профиле пользователя Windows,
удалите папку `data`.

**Запуск:** `appMyCodeApp.exe`. Варианты командной строки:

| Команда | Действие |
|---|---|
| `appMyCodeApp.exe` | открыть последнюю папку проекта и её вкладки |
| `appMyCodeApp.exe файл1 файл2` | открыть файлы вкладками |
| `appMyCodeApp.exe папка` | открыть папку как проект |
| `appMyCodeApp.exe --profile имя` | запустить с отдельным набором настроек (профилем) |
| `appMyCodeApp --software` | программная отрисовка без видеокарты; на Linux включается сама, если OpenGL недоступен |

Если программа уже запущена, повторный запуск передаёт файлы открытому окну
и сразу завершается. Программы с разными профилями работают одновременно.

**Открытие из Проводника.** Выберите «Файл → Добавить в «Открыть с помощью»».
После этого в Проводнике:
- щелчок правой кнопкой по файлу → «Открыть с помощью» → MyCodeApp;
- щелчок правой кнопкой по папке или по пустому месту внутри неё →
  «Открыть в MyCodeApp» (в Windows 11 — в «Показать дополнительные параметры»).

Регистрация привязана к текущему расположению программы. После переноса
программы выполните её заново. Отменить — «Файл → Убрать из «Открыть с помощью»».

Файлы и папки можно также перетащить в окно программы.

### 3.2 Окно программы

```
┌ Меню: Файл Правка Поиск Код Git Ассистент Плагины Вид Справка ────────────┐
│ Боковая панель      │ Вкладки файлов                                      │
│ Файлы│Поиск│Git│Асс. │─────────────────────────────────────────┬──────────│
│                     │ Номера │ Текст                           │ Миникарта│
│ дерево / результаты │ строк  │                                 │          │
│ поиска / панель Git │        │                                 │          │
│                     ├────────┴─────────────────────────────────┴──────────│
│                     │ Нижняя панель: «Проблемы» и «Ссылки» (по запросу)   │
├─────────────────────┴─────────────────────────────────────────────────────┤
│ Строка состояния: путь · ветка · ошибки · сервер · Стр, Стлб · кодировка …│
└───────────────────────────────────────────────────────────────────────────┘
```

- **Боковая панель** (Ctrl+B — показать или скрыть, ширина меняется
  перетаскиванием края): вкладки «Проводник», «Поиск», «Git», «Ассистент»
  (переключаются значками в колонке слева).
- **Вкладки**: точка вместо крестика — файл изменён и не сохранён.
  Переключение — Ctrl+Tab и Ctrl+Shift+Tab. Вкладку можно перетащить мышью
  в правую половину области редактора — файл откроется справа (два файла рядом;
  ширина половин меняется перетаскиванием зазора между ними). Команды меню, поиск
  и строка состояния относятся к половине, в которой курсор.
- **Перенос строк** («Вид → Переносить строки», Alt+Z, включён по умолчанию):
  длинные строки переносятся по ширине окна, продолжение выравнивается по отступу
  строки. Файлы больше 100 000 строк и строки длиннее 10 000 символов не переносятся.
- **Область номеров строк**: номер, маркеры сворачивания (при наведении),
  полоски изменений Git.
- **Миникарта**: уменьшенный текст. Перетаскивание рамки или щелчок
  прокручивают редактор, Ctrl+колесо меняет масштаб.
- **Строка состояния**: путь файла (на время — сообщения программы), ветка Git,
  число ошибок и предупреждений (щелчок открывает «Проблемы»), состояние
  языкового сервера, «Только чтение», число курсоров, позиция курсора,
  кодировка, перевод строк, язык.

### 3.3 Работа с файлами

| Действие | Как выполнить |
|---|---|
| Открыть файл | «Файл → Открыть…» (Ctrl+O), перетаскивание в окно, Ctrl+P в проекте |
| Сохранить | Ctrl+S. Файл записывается в исходной кодировке и с исходными переводами строк, атомарно: при сбое во время записи старая версия не теряется |
| Закрыть вкладку | Ctrl+W или крестик. Если есть несохранённые правки, программа предложит «Сохранить», «Не сохранять» или «Отмена» |

**Большие файлы.** Файлы больше 20 МБ загружаются в фоне с индикатором
прогресса. Файлы от 256 МБ открываются только для чтения: в строке состояния —
«Только чтение», правка и сохранение недоступны.

**Изменение файла другой программой.** Если файл не правился в редакторе, он
перечитывается автоматически. Если в редакторе есть несохранённые правки,
появляется вопрос «Загрузить с диска» (правки пропадут) или «Оставить мою».

### 3.4 Редактирование

**Основное.** Отмена — Ctrl+Z, повтор — Ctrl+Y. Набранный подряд текст
отменяется одним шагом. Отмена до состояния на момент сохранения снимает отметку
«изменён».

**Умный ввод:**
- скобки и кавычки закрываются автоматически; набранная закрывающая скобка
  перешагивается;
- выделенный текст при вводе скобки или кавычки оборачивается ею;
- Enter сохраняет отступ и добавляет его после `{` (и `:` в Python);
- Tab и Shift+Tab сдвигают выделенные строки; отступ табами или пробелами
  определяется по файлу;
- Home переводит курсор к первому непробельному символу, повторное нажатие — в начало строки.

**Несколько курсоров:**

| Действие | Клавиши |
|---|---|
| Добавить курсор | Alt+щелчок |
| Курсор выше / ниже | Ctrl+Alt+↑ / Ctrl+Alt+↓ |
| Выделить следующее такое же слово | Ctrl+D |
| Выделение столбцом | Alt+Shift+стрелки или Alt+перетаскивание |
| Оставить один курсор | Esc |

Ввод, удаление и вставка работают на всех курсорах сразу и отменяются одним шагом.

**Сворачивание блоков.** Наведите указатель на номера строк — у блоков
появятся маркеры ▾; щелчок сворачивает блок, на его месте — плашка «…»
(щелчок по ней разворачивает). С клавиатуры: Ctrl+Shift+[ / Ctrl+Shift+] —
блок под курсором, Ctrl+K Ctrl+0 / Ctrl+K Ctrl+J — все блоки.

**Сниппеты** — заготовки текста. Наберите сокращение и нажмите Tab:

| Язык | Сокращения |
|---|---|
| C/C++ | `for`, `forr`, `if`, `ife`, `while`, `switch`, `class`, `struct`, `qobject`, `main`, `lambda`, `namespace`, `inc`, `once` |
| Python | `def`, `class`, `for`, `if`, `main`, `with`, `try` |
| QML | `item`, `rect`, `prop`, `fn`, `conn`, `timer` |

После раскрытия Tab переходит к следующему полю ввода, Shift+Tab — к предыдущему,
Esc завершает заполнение. Одинаковые поля (например, имя переменной цикла)
меняются одновременно. Сниппеты показываются и в списке автодополнения.

### 3.5 Поиск и навигация

| Действие | Как выполнить |
|---|---|
| Найти в файле | Ctrl+F: строка поиска в правом верхнем углу; F3 / Shift+F3 — следующее и предыдущее совпадение; «Aa» — учитывать регистр; Esc — закрыть |
| Перейти к строке | Ctrl+G, ввести номер строки или `строка:столбец`, Enter |
| Перейти к файлу проекта | Ctrl+P, ввести часть имени или пути, Enter |
| Найти во всех файлах | Ctrl+Shift+F: результаты сгруппированы по файлам; ↓ из поля — к результатам, Enter — открыть |
| Перейти в боковую панель / в редактор | Ctrl+0 / Ctrl+1 или Esc |

### 3.6 Работа с проектом

**Открыть папку:** «Файл → Открыть папку…» (Ctrl+K Ctrl+O) или перетаскивание
папки в окно. При следующем запуске папка и её вкладки (с позициями курсора
и прокрутки) открываются снова.

**Проводник** показывает дерево папки без файлов, исключённых `.gitignore`.
Поле «Фильтр файлов» превращает дерево в список подходящих файлов.
С клавиатуры: Ctrl+0, стрелки, Enter (открыть файл или раскрыть папку).
Цветом и буквой справа отмечено состояние в Git (см. 3.8).

**Закрыть папку:** «Файл → Закрыть папку».

### 3.7 Помощь языкового сервера

Работает для файлов, у которых найден языковой сервер (раздел 2).
Состояние сервера показано в строке состояния: «запуск», «индексация…»,
«не найден» и т.п.

| Функция | Как вызвать |
|---|---|
| Автодополнение | появляется при наборе; Ctrl+Space — вызвать; ↑/↓ — выбор, Enter или Tab — вставить, Esc — закрыть; справа — описание варианта |
| Подсказка | задержать указатель над символом |
| Перейти к определению | F12 или Ctrl+щелчок; назад — Alt+← |
| Найти ссылки | Shift+F12 — список в нижней панели |
| Переименовать символ | F2, ввести имя, Enter; правка во всех файлах отменяется Ctrl+Z |
| Форматировать файл | Shift+Alt+F |
| Ошибки и предупреждения | подчёркнуты волнистой линией; список — Ctrl+Shift+M (панель «Проблемы»), щелчок по строке переходит к месту |

### 3.8 Работа с Git

Функции доступны, если папка проекта находится в репозитории Git или Mercurial
(используется ближайший вверх по папкам). Заголовок боковой вкладки показывает,
какой именно. Если репозитория нет — на вкладке есть кнопка «Создать репозиторий»
(создаётся репозиторий Git).

**Состояние файлов** — буквы в Проводнике и панели Git:

| Буква | Значение |
|---|---|
| M | изменён |
| A | добавлен в индекс |
| U | новый, не отслеживается |
| D | удалён |
| R | переименован |
| C | конфликт слияния |

У папки точка означает, что внутри есть изменения.

**Изменения в редакторе.** Полоски в области номеров строк: зелёная — строки
добавлены, синяя — изменены, красная метка — строки удалены. Переход между
изменениями — Alt+F5 / Shift+Alt+F5.

**Просмотр изменений файла:** «Git → Изменения файла» (Ctrl+K D) или щелчок по
файлу в панели Git. Удалённые строки показаны красным фоном, добавленные —
зелёным; кнопки ↑ ↓ — к предыдущему и следующему изменению, Esc — закрыть.

**Панель Git** (Ctrl+Shift+G):
1. Разделы «Индексированные» (войдут в коммит) и «Изменения».
2. Кнопки у файла (при наведении): «+» — добавить в индекс, «−» — убрать,
   «↺» — отменить изменения (после подтверждения; новый файл удаляется),
   «↗» — открыть файл. Кнопки в заголовке раздела действуют на все файлы.
3. Введите сообщение и нажмите «Коммит» или Ctrl+Enter.

**Ветки.** Кнопка с именем ветки вверху панели открывает список: выбор
ветки переключает на неё, «Новая ветка…» создаёт ветку от текущей и переключает.
Переключение не выполняется, если оно перезаписало бы несохранённые в Git правки.

**Mercurial.** Индекса у Mercurial нет, поэтому раздел «Индексированные»
называется «В коммит»: кнопка «+» отмечает файл для следующего коммита, «−»
снимает отметку. Отметки хранятся до закрытия программы или смены папки.
Новые файлы из списка при коммите добавляются под контроль, пропавшие —
удаляются из него. «Новая ветка…» создаёт закладку (bookmark); в списке веток —
закладки и именованные ветки.

**История** — кнопка «История» в панели или «Git → История» (Ctrl+K H).
Открывается поверх редактора:
1. Список коммитов всех веток, от новых к старым. Слева — граф: каждая ветка
   на своей дорожке своим цветом, коммит рабочей копии отмечен кольцом. Рядом
   с сообщением — метки веток, закладок и тегов (текущая ветка выделена рамкой,
   теги — курсивом), справа — автор, дата и начало хэша.
2. Поле поиска вверху: текст из сообщения, имя автора или начало хэша, Enter —
   следующий найденный коммит. Ctrl+F в списке переходит в поле поиска.
3. Внизу — полное сообщение, автор, дата и хэш выбранного коммита (выделяются и
   копируются) и его файлы. Щелчок по файлу показывает его изменения в этом
   коммите. Высота нижней части меняется перетаскиванием её границы.
4. Правый щелчок по коммиту: «Переключиться на этот коммит» (рабочая копия
   переходит на коммит без ветки), «Новая ветка отсюда…», «Копировать хэш».
5. История обновляется сама после коммита и переключения ветки; кнопка
   «Обновить» — вручную. Esc или крестик — закрыть, выбор вкладки файла —
   тоже закрывает историю.

### 3.9 Настройка

Окно настроек — «Файл → Настройки…» (Ctrl+,).

**Внешний вид → Язык.** Русский или English, применяется сразу.

**Внешний вид → Тема.** «Графит (тёмная)», «Бумага (светлая)» и свои темы.
«Создать свою тему» открывает копию текущей темы во вкладке: измените цвета
и сохраните файл — они применятся сразу (формат — приложение В).

**Горячие клавиши.** Список всех команд меню. Щёлкните по сочетанию и нажмите
новое; Esc — отмена, Backspace — убрать сочетание, «↺» — вернуть сочетание
по умолчанию, «Сбросить все» — вернуть все. Если сочетание было у другой
команды, оно снимается с неё (внизу окна появится сообщение). Двойные
сочетания вида `Ctrl+K, D` задаются в файле `keybindings.json`.

**Свои сниппеты:** «Код → Свои сниппеты для этого языка…» открывает файл
сниппетов текущего языка (формат — приложение В); после сохранения они
сразу работают.

**Вид:** показать или скрыть боковую панель и миникарту, масштаб миникарты.

### 3.10 Плагины

Меню «Плагины» содержит команды загруженных плагинов. Поставляется плагин
«Инструменты текста»:

| Команда | Действие |
|---|---|
| Текст: в верхний регистр (Ctrl+Shift+U) | выделение или, если ничего не выделено, весь текст |
| Текст: в нижний регистр (Ctrl+Shift+L) | то же |
| Текст: сортировать строки | сортировка строк выделения или файла |
| Текст: убрать повторяющиеся строки | удаление повторов |
| Текст: вставить дату и время | вставка в позицию курсора |

**Управление:** «Плагины → Управление плагинами…» — список плагинов с версией,
описанием и путём; «Выключить» / «Включить» действуют сразу. Чтобы установить
плагин, скопируйте его DLL в папку `plugins` рядом с программой или в папке
данных («Открыть папку плагинов») и нажмите «Обновить список».

### 3.11 Ассистент

Ассистент объясняет код и ошибки, пишет документирующие комментарии, пересказывает
журналы и предлагает сообщения коммитов. Он работает с языковой моделью на этом
компьютере или на сервере в локальной сети: код и журналы в интернет не передаются.
Язык ответов совпадает с языком интерфейса.

**Подготовка (один раз):**
1. Установите Ollama (ollama.com) и скачайте модель: `ollama pull qwen3:4b-instruct`
   (2,5 ГБ, лицензия Apache 2.0).
2. Откройте панель ассистента (значок с репликой в колонке слева или Ctrl+Shift+A).
   Строка над разговором показывает модель; точка перед ней — состояние сервера.
   Если сервер не отвечает, в панели будет причина и кнопки «Проверить снова» и
   «Настройки».

Без видеокарты ответ занимает от полуминуты до полутора минут: сначала модель
читает запрос («Модель читает запрос… N с»), затем пишет ответ, который виден по
мере написания. «Стоп» прерывает ответ.

**Действия** (меню «Ассистент», кнопки в пустой панели):

| Действие | Как вызвать | Что отправляется модели |
|---|---|---|
| Объяснить код | Ctrl+K E | выделенный код; без выделения — фрагмент вокруг курсора |
| Комментарий к выделенному | Ctrl+K C | выделенная функция или класс; под ответом — «Вставить комментарий» (вставляет над кодом; в Python — docstring внутрь функции) |
| Объяснить ошибку в строке | Ctrl+K P, или «Объяснить» у строки в «Проблемах» (при наведении) | сообщение компилятора или языкового сервера и код вокруг |
| Пересказать журнал | меню «Ассистент» | выделенные строки или весь файл: начало, все ошибки и предупреждения (повторы схлопнуты) и конец |
| Сообщение коммита | кнопка «Предложить» рядом с «Коммит» в панели Git | изменения отмеченных файлов (без отметок — все изменения); текст появляется в поле сообщения, его можно править |

**Свой вопрос** — в поле внизу панели: Enter — отправить, Shift+Enter — новая
строка. Если в редакторе что-то выделено, флажок «С выделенным кодом» прикладывает
это к вопросу. Ассистент помнит разговор: можно уточнять. Кнопка «+» над разговором
начинает новый.

**Под ответом:** «Копировать» — весь ответ в буфер обмена; «Вставить код» — первый
блок кода из ответа вместо выделения в редакторе; рядом — время ответа и скорость.

**Настройки** («Файл → Настройки… → Ассистент» или значок над разговором):
- сервер модели: Ollama или OpenAI-совместимый сервер (llama.cpp server, vLLM,
  LM Studio); адрес — по умолчанию `http://127.0.0.1:11434` (Ollama) или
  `http://127.0.0.1:8080`;
- модель: имя или выбор из списка моделей сервера («Выбрать»);
- ключ доступа — только для сервера, который его требует;
- контекст модели — 4, 8 или 16 тыс. токенов: больше — длиннее фрагменты, но больше
  памяти (у Qwen3-4B около 3,1 ГБ при 4 тыс. и 3,8 ГБ при 8 тыс.);
- «Проверить подключение» — есть ли связь и нужная модель.

Модель можно запустить на более мощной машине в локальной сети и указать её адрес:
у Ollama для этого задаётся переменная окружения `OLLAMA_HOST=0.0.0.0`.

### 3.12 Завершение работы и восстановление после сбоя

**Завершение:** «Файл → Выход» (Ctrl+Q) или закрытие окна. Открытые вкладки
запоминаются для папки проекта.

**Несохранённые правки не теряются.** Правки, которые не были сохранены
(при закрытии окна или сбое программы), записываются в журнал. При следующем
запуске такие файлы открываются с этими правками; Ctrl+Z возвращает версию
с диска. Если файл за это время изменился на диске, журнал не применяется.

## Приложение В. Форматы файлов настройки

**Тема** (`themes\*.json`). Указываются только меняемые цвета, остальные
берутся из базовой темы:

```json
{
    "name": "Моя тема",
    "base": "dark",
    "ui": { "accent": "#c678dd" },
    "editor": { "background": "#1b1b1f", "selection": "#3a3f5a" },
    "syntax": { "keyword": "#c678dd", "string": "#98c379", "comment": "#6b7080" }
}
```

Полный список ключей — в созданной через «Создать свою тему» копии.

**Сниппеты** (`snippets\<язык>.json`, язык — `cpp`, `python`, `qml`, `json`,
`markdown`, `text`; `global.json` — для всех языков):

```json
{
    "Вывод в консоль": {
        "prefix": "cout",
        "body": ["std::cout << ${1:value} << '\\n';$0"],
        "description": "std::cout"
    }
}
```

В теле: `$1`, `$2` — поля ввода по порядку, `${1:текст}` — поле с подсказкой,
`${1|a,b|}` — выбор (вставляется первый вариант), `$0` — положение курсора в
конце, `$TM_FILENAME`, `$TM_FILENAME_BASE`, `$TM_SELECTED_TEXT`, `$CLIPBOARD`,
`$CURRENT_YEAR`, `$CURRENT_MONTH`, `$CURRENT_DATE` — подстановки.

**Горячие клавиши** (`keybindings.json`) — идентификатор команды и сочетание;
пустая строка — без сочетания:

```json
{
    "file.save": "Ctrl+Alt+S",
    "git.fileDiff": "Ctrl+K, Ctrl+D",
    "edit.selectNextOccurrence": ""
}
```

Идентификаторы команд имеют вид `группа.действие` (например `find.goToLine`,
`view.focusSidebar`); их значения по умолчанию видны в окне настроек.

**Языковой сервер** (`lsp.json`) — описание заменяет встроенное целиком:

```json
{
    "servers": {
        "pyright": {
            "extensions": ["py"],
            "command": ["C:/tools/pyright-langserver.cmd", "--stdio"]
        }
    }
}
```
