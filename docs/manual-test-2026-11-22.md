## 1. Большие файлы ≥256 МБ (mmap) — новая функциональность

### 1.1 Открытие и скролл
- **Как:** открыть `big1g.log`. Строка состояния: во время загрузки — имя + прогресс; ждать ~2–5 с.
- **Результат:** файл открыт; строка пути заменена содержимым; прокрутка колесом и тягой полосы — плавная, «Стр N» в статусе меняется; RAM в диспетчере задач у приложения — сотни МБ, не гигабайты.
- Прыгнуть в середину (Ctrl+G, номер строки ~600000, Enter): курсор встаёт, текст виден.

### 1.2 Редактирование и сохранение (ключевой сценарий)
- **Как:** в `big1g.log` набрать в начале текст «ПРОБА », ниже — пару строк. Ctrl+S.
- **Результат:** статус-бар показывает «Сохранение… NN%» (несколько секунд); затем снимается. Вкладка остаётся, «изменён»-точка гаснет. Закрыть вкладку и открыть файл заново правкой (Ctrl+W, заново открыть) — правки на диске.
- После сохранения Ctrl+Z (отмена) — файл снова dirty; ещё Ctrl+Z до конца → вернулся к сохранённому, dirty погас.

### 1.3 Сохранение не глотает чужие ошибки
- **Как:** во время «Сохранение…» (сразу после Ctrl+S на 1 ГБ) успеть нажать Ctrl+W, Ctrl+Q.
- **Результат:** закрытие вкладки/окна блокируется («Подождите: файл ещё сохраняется»), через ~3 с закрытие работает.

### 1.4 Ограничение кодировок
- **Как:** открыть `cp1251-sample.txt` — обычный режим. Ощутимо: большие файлы ≥256 МБ в cp1251 откроются только для чтения.
- **Результат:** статус «Только чтение». Это согласованное ограничение (см. раздел отступлений в акте приёмки).

### 1.5 Внешнее изменение mmap-файла (R13)
- **Как:** открыть `big1g.log`, править (не сохранять!), затем в Проводнике/другой программе заменить содержимое файла (например, дописать в конец байты через `copy /b big1g.log+redos.txt`).
- **Результат:** через ~2 с диалог «файл изменён на диске»: «Загрузить с диска» / «Оставить мою». Выбор работает: после «Оставить мою» вопрос не переспрашивается (принято); после «Загрузить» — чужая версия, свои правки пропали.

## 2. Поиск (новое: целое слово и regex)

### 2.1 Обычный поиск
- **Как:** Ctrl+F в `git-sample/alpha.cpp`, искать `func`. F3/Shift+F3 — ходить.
- **Результат:** подсветка совпадений, счётчик «N из M», Esc гасит.

### 2.2 Целое слово («ab»)
- **Как:** найти `func` с включённой «ab». Затем «Aa+ab» — `Func`.
- **Результат:** совпадает только отдельно стоящее слово: под `funcA`/`funcB` попадает `func` префикса, но `return` без слова и т.п.; комбинированная работа «Aa»+«ab» — регистр учитывается.

### 2.3 Регэксп («.*»)
- **Как:** Ctrl+F, включить «.*», найти `func\w\+\(` и `^\s*//`.
- **Результат:** совпадения с правильной длиной (длинный regex не съедает соседние слова); `^`/`$` — по строке. Прыгать F3, счётчик корректен.

### 2.4 Ошибка регэкспа
- **Как:** ввести `a(` в строке поиска с «.*».
- **Результат:** в поле поиска появляется «Ошибка: …» (не диалог об ошибке файла), совпадения 0; исправить валидным — счётчик возвращается.

### 2.5 ReDoS-предохранитель
- **Как:** открыть `regex-flood.txt`, Ctrl+F, «.*», поиск `^a+.*x` (дать просчитаться 5–10 с). Затем в `redos.txt` — поиск `(a+)+b`.
- **Результат:** сканирование прерывается с частичным результатом (или «нет совпадений»), интерфейс живой весь поиск; окно не зависает.

### 2.6 Поиск по проекту
- **Как:** открыть папку `git-sample`, Ctrl+Shift+F, искать `func`; повторить с «ab» и «.*» (`func\w`). Проверить регистр «Aa»+`Func`.
- **Результат:** результаты сгруппированы по файлам с превью и подсветкой; при «.*» с ошибкой выражения — красная строка «Ошибка регэкспа: …» под полем.

## 3. Кодировки и окончания строк

- **Как:** по очереди открыть `cp1251-sample.txt`, `utf16le-sample.txt`, `latin1-sample.txt` — статус-бар показывает кодировку (Windows-1251 / UTF-16 LE / Latin-1). Подправить русский текст в cp1251-файле, Ctrl+S, открыть в «Блокноте» (или `certutil -dump`) — совпадает.
- **Результат:** кодировки угаданы; сохранение в исходной кодировке; символ «№» в cp1251 сохраняется.
- **Окончания:** открыть `endings-mix.txt`; статус — «CRLF» (побеждает), длинная строка — с переносом (Alt+Z включить/выключить). «Файл → Сохранить с окончаниями строк → LF»: после сохранения CRLF-строк стали LF (открыть в hex-вью/блокноте).

## 4. Отдельное окно (открепление вкладки) — новая функциональность

### 4.1 Открепить через меню
- **Как:** правый клик по вкладке `git-sample/alpha.cpp` → «Открепить в отдельное окно».
- **Результат:** появляется второе окно с рамкой ОС: свои вкладки, статус-бар, курсор/прокрутка на месте. В главном окне активировалась соседняя вкладка.

### 4.2 Открепить перетаскиванием
- **Как:** подвести вкладку за заголовок тянуть за границу окна и отпустить снаружи.
- **Результат:** вкладка уехала в новое окно.

### 4.3 Обратный перенос
- **Как:** правый клик по вкладке отдельного окна → «Вернуть в главное окно».
- **Результат:** вкладка вернулась в конец списка главного окна, курсоры/скролл сохранены, отдельное окно закрылось.

### 4.4 Работа в отдельном окне
- **Как:** в отдельном окне: править текст, Ctrl+S; Ctrl+F (+режимы), Ctrl+G; F12-определения (clangd с проектом compile_commands или .vscode — если сервер есть); Ctrl+Shift+A — панель ассистента, спросить.
- **Результат:** всё работает как в главном. «Остановить ответ» гасит ассистента. Ctrl+W при несохранённых — диалог «Сохранить/Не сохранять/Отмена».

### 4.5 Мусорное закрытие
- **Как:** в отдельном окне с несохранённой правкой закрыть крестик окна.
- **Результат:** вопрос закрытия; «Не сохранять» закрывает и окно; вкладка исчезла из главного окна (она была отдана).

## 5. Git

- **Как:** открыть папку `git-sample` (Файл → Открыть папку). Панель Ctrl+Shift+G: изменить `alpha.cpp`, сохранить — буква M в дереве, полоска в gutter, вкладка в индекс → коммит. Смотреть «Изменения файла» (Ctrl+K D) и Историю (Ctrl+K H): граф, файлы коммита.
- **Результат:** статус-бар «Ветка: …»; diff по строкам; история и откат изменений работают; при отсутствии Git — статус корректен («Git недоступен»), приложение не падает.
- Mercurial аналогично при установленном hg.

## 6. Ассистент (офлайн)

- **Как:** Оллама на 127.0.0.1:11434 с моделью `qwen3:4b-instruct` (Настройки → Ассистент; «Проверить подключение»). Ctrl+K E — объяснить код; Ctrl+K C — комментарий; Ctrl+K P — объяснить ошибку в строке; пересказать лог-файл.
- **Результат:** ответ приходит потоком; панель показывает статистику; «Остановить ответ» работает; комментарий вставляется над функцией; при выключенном сервере — сообщение, не падение.

## 7. Восстановление после сбоя

- **Как:** открыть `git-sample/alpha.cpp`, править БЕЗ сохранения, убить приложение (Диспетчер задач, end task или второй экземпляр). Запустить заново.
- **Результат:** «Восстановить…» / восстановление вкладок с несохранёнными правками; правки на месте; после Ctrl+S журнал очищается.

## 8. Метрики (замеры руками)

- **Скролл 60 FPS.** `big.log`: удерживать PgDn/тянуть полосу ~10 с: без рывков; глазная оценка — плавно. *(Аналогичный автозамер невозможен offscreen — глаз оператора.)*
- **Запуск.** Старт с папкой из сессии: до видимого окна ≤ 1 с (SSD).
- **Большая правка.** В `big1g.log` выделить 3 страницы, вставить вместо них строку; сразу отпечатать 20 символов без пауз — набор без запинки.
- **Поиск.** По `big.log` поиск «строка» — счётчик — через доли секунды; поиск по 1 ГБ «строка» — несколько секунд, прогресс виден, UI живой.
