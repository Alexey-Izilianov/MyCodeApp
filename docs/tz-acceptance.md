## Отступления от ТЗ (согласованные)

1. **F-1.7** TextMate → tree-sitter: фоновый разбор с инкрементальным пересчётом; JSON — регэкспы. Принято 2026-09-26/29.
2. **Автосохранение на диск** заменено журналом восстановления (атомарные правки в `<данные>/recovery/*.log`, раз в секунду + при выходе): файл на диске меняется только оператором. Принято на M2-9.
3. **Терминал (F-3.4)** исключён: QTermWidget/Qt6 ненадёжен. Реестр решений 2026-09-19.
4. **Кодировки файлов ≥256 МБ** — только UTF-8/Latin-1 (требование mmap: '\n' однобайтовый).
5. **Отдельное окно**: рамка ОС, без дерева проекта/панели Git; вкладки отдельного окна не сохраняются в сессию. 2026-11-22.
6. **Только один «системный» пункт темы**: авто-переключение по системе отсутствует.
