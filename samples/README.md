# Тестовые файлы

Файлы для быстрой ручной проверки редактора. `small/` лежит в репозитории,
`medium/` и `large/` создаёт скрипт (в git их нет):

```bash
python samples/generate.py          # small (особые кодировки) + medium + large, ~16 с, ~270 МБ
python samples/generate.py --huge   # плюс large/huge.log на 1 ГБ (цель ТЗ)
```

Содержимое генерируется с фиксированным seed — у всех одинаковое.

## small/ — до 10 КБ: подсветка и правила ввода

| Файл | Что проверять |
|---|---|
| `hello.cpp`, `widget.h` | подсветка C++: препроцессор (красный), шаблоны, лямбды, raw-строки, escape, числа |
| `script.py` | Python: декораторы, docstring на несколько строк, f-строки, `match`, `async` |
| `Main.qml` | QML: типы, свойства, сигналы, JavaScript внутри |
| `config.json`, `notes.md` | подсветка регулярными выражениями |
| `brackets.cpp` | подсветка парных скобок, в том числе непарных |
| `multicursor.txt` | Ctrl+D, выделение столбцом, вставка строк на несколько курсоров |
| `tabs.c` | табуляция: ровные отступы, клики и стрелки по табстопам, Tab вставляет таб |
| `crlf_windows.txt` | переводы строк CRLF: в статус-баре CRLF, сохраняется как CRLF |
| `cp1251.txt` | кодировка Windows-1251 определяется, текст читается |
| `utf16le.txt` | UTF-16 LE с BOM |
| `unicode.txt` | разные письменности; эмодзи — курсор не встаёт внутрь символа |
| `empty.txt` | пустой файл |

## medium/ — ~0,5–5 МБ: скорость на обычных больших файлах

| Файл | Размер | Что проверять |
|---|---|---|
| `engine.cpp` | 1 МБ | tree-sitter: первый разбор, правки в середине, прокрутка |
| `analysis.py` | 1 МБ | то же для Python |
| `Dashboard.qml` | 0,5 МБ | то же для QML |
| `dataset.json` | 1 МБ | подсветка регэкспами, Ctrl+D по ключам |
| `manual.md` | 0,5 МБ | Markdown |
| `server.log` | 5 МБ | поиск (Ctrl+F) по тысячам совпадений |

## large/ — 7,5–150 МБ: предельные случаи

| Файл | Размер | Что проверять |
|---|---|---|
| `near_limit.cpp` | 7,5 МБ | чуть меньше предела tree-sitter (8 млн символов) — подсветка полная |
| `over_limit.cpp` | 20 МБ | больше предела — подсветка регэкспами (типы и функции не выделяются) |
| `big.py` | 20 МБ | то же для Python |
| `data.json` | 50 МБ | фоновая загрузка с прогрессом (> 20 МБ), прокрутка |
| `app.log` | 150 МБ | загрузка, прокрутка, поиск на большом объёме |
| `long_line.json` | 10 МБ | одна строка: горизонтальная прокрутка, ввод в конце строки |
| `huge.log` | 1 ГБ | только с `--huge`: открытие файла на 1 ГБ (цель ТЗ — < 5 с) |

Известное ограничение сетки колонок: широкие символы (CJK, эмодзи) и символы,
которых нет в Cascadia Mono, занимают больше одной клетки — курсор правее
них смещается.
